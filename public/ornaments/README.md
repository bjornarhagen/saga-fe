# Saga ornaments

Original Saga vector ornaments copied from the owner's `brain` repository:
`public/workspace/ornaments/v1/{bjornarhagen,girlypop,matrix}/`.
The flagship assets keep their existing paths; Girlypop and Matrix each have
a subfolder.

The source asset provenance records these as original vector geometry made
for Saga on 7 September 2026. The original paths are unchanged. The current
dashboard uses each theme's header mark in the brand and a restrained corner
branch in the forecast callout. Other copied variants remain available for
matching future views. Large source engravings are not included.

The SVGs contain no scripts, fonts, or external resources. They use
`currentColor`; CSS masks let them follow the active theme and mode.
They are decorative and never convey transaction or forecast state.
