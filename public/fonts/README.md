# Saga Fé fonts

These self-hosted WOFF2 subsets are copied from the owner's `brain` project.
They use its existing font declarations and weight ranges:

- **JetBrains Mono** — UI and figures; variable weights 400–800.
  Copyright 2020 The JetBrains Mono Project Authors.
- **IBM Plex Sans** — body text; variable weights 100–700.
  Copyright 2017 IBM Corp.
- **Pirata One** — brand and display headings; static weight 400.
  Copyright 2011 The Pirata One Project Authors.

Each font's directory contains its SIL Open Font License 1.1, obtained from
the corresponding family in the official Google Fonts repository. No font
request is made to a CDN. The font CSS lives in `src/styles/fonts.css`.
